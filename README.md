super Store Interactive Excel Dashboard
This project is an interactive Excel dashboard created using Microsoft Excel to analyze and visualize Super Store sales data. 
The dashboard provides meaningful insights into sales performance, transactions, quantities, regions, categories, customers, and yearly trends.
🔹 Key Features

📈 Total Sales, Average Sales, Transactions & Quantities KPIs

🌍 Region-wise analysis (Central, East, South, West)

🚚 Ship Mode distribution

🏙️ Top 5 cities by sales

🗂️ Category-wise transaction count

👥 Customer segment-wise quantity order

📅 Year-wise quantity trend (2014–2017)
